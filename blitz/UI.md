# UI.md — SuperSGames 공통 UI 작업 안내 (경량판, 2026-11-15)

**상세 규칙의 유일한 원본:** [SuperSGames 공통 UI v4.0 전문](https://github.com/SuperSGames/SuperSGames/blob/main/PROJECT_TEMPLATES/UI.md). UI 이미지 제작·수정·적용 전에는 이 전문과 해당 게임 소스·현재 UI 에셋을 읽는다. 이 문서는 전문의 내용을 바꾸지 않고, 프로젝트마다 복제되어 있던 동일한 47,177바이트 문서를 짧은 진입 문서로 대체한 것이다. 원본은 `backup/docs-precleanup-2026-11-15` 브랜치에도 보존되어 있다.

## 항상 적용할 핵심
1. **기존 이미지와 기능 보존.** 사용자가 승인한 게임별 원화·레이아웃·버튼 이름·상태·비율을 임의 변경하지 않는다. 그릴 요소는 실제 게임 화면과 기능을 먼저 조사한다.
2. **그림과 상태를 분리.** 이미지에는 고정 장식·프레임·고정 아이콘만 넣는다. 숫자·개수·점수·시간·게이지 채움·가변 글자·알림(!, NEW, 빨간 점) 등 상태는 코드의 별도 레이어에 표시한다.
3. **각 클릭 요소는 독립 에셋.** 버튼·X·탭마다 기본(normal)과 눌림(pressed) 원화가 모두 필요하다. ON/OFF 스위치는 각각 normal/pressed 4상태. 선택/비활성은 실제 필요한 경우 별도로 준비한다. 각 셀에는 한 요소의 한 상태만 둔다.
4. **일러스트 도형 조립 금지.** SVG, CSS·Canvas 기하도형/이모지 조합으로 그림·아이콘·버튼·배경을 대신 만들지 않는다. 승인된 이미지 에셋 또는 새로 그린 이미지로 제작한다.
5. **스프라이트 실제 픽셀 검증.** R×C 각각 동일한 셀 크기(미지정 시 256×256px), 최종 가로=C×셀 너비/세로=R×셀 높이. 배경은 RGBA 완전 투명이고 셀 외곽 2px은 예외 없이 alpha=0이다. 그림·그림자·효과가 인접 셀을 침범하지 않아야 한다. 격자선·테두리선·배경은 넣지 않는다. 검사 실패 시 납품하지 않는다.
6. **게임 화면 좌표 보호.** 논리 화면 414×896을 유지하며 최상위 게임 컨테이너만 화면에 맞춰 변환한다. 기존 터치/좌표·세로화면·하단 고정 바와 펀치홀 안전 여백을 훼손하지 않는다. 화면 스케일의 과거 상충 지침은 현재 코드·최신 확정 규칙을 확인한 후 적용한다.
7. **적용 검증.** 이미지를 생성한 것과 UI를 실제 게임에 연결한 것, GitHub 반영, Cloudflare 테스트웹 검증을 각각 구분한다.

게임별 추가 규칙이 공통 규칙과 충돌하면 최신 확정 지시 및 실제 정상본을 대조해 처리하고, 확인되지 않은 사항은 임의 변경하지 않는다.
