# blitz 게임 작업 지침

- **UI 이미지를 새로 만들거나 수정·적용할 때는 이 폴더의 [UI.md](UI.md)를 반드시 읽고 따른다.**
- 기본 이미지에는 가변 숫자·문구·게이지 채움·편지 느낌표(!)/NEW/빨간 점을 그리지 않는다. 상태 정보는 프로그램에서 별도 표시한다.
- 스프라이트 시트는 완전 투명 PNG RGBA, 각 셀 바깥 2px alpha=0, 셀 간 침범/겹침 금지. 실제 픽셀을 검증한다.
- 기존 정상 게임/에셋/버튼/저장 기능을 요청 없이 변경하지 않는다.
- 추가로 상위 저장소의 [공통 AGENTS.md](../AGENTS.md)를 따른다.
