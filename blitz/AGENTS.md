# blitz 게임 작업 지침

## [최우선 v4.0] 모든 클릭 버튼 상태 원화 필수 (2026-11-13)

- **UI 원화 제작 전 반드시 이 저장소의 UI.md v4.0 전문을 읽는다.** 실제 최신 게임의 모든 화면에서 클릭 가능한 버튼·탭·X·스위치·상점·광고 UI를 전수조사하고 고유 기능/크기/상태 목록을 만든다. 메인에 항상 보이는 주요 버튼을 누락하지 않는다.
- **각 클릭 버튼마다 별도의 normal + pressed 원화를 반드시 제작한다.** 버튼이 여러 개면 각 버튼의 쌍을 모두 만들며, 닫기 X·작은 아이콘 버튼·하단 탭도 예외 없다. 선택·비활성 상태는 실제 기능이 있을 때 추가하고, **ON/OFF 스위치는 on/off 각각 normal/pressed (4종)**를 만든다.
- **한 셀에는 한 요소의 한 상태만.** 다른 버튼/버튼 상태/팝업을 한 그림에 합치지 않는다. 버튼판·아이콘·문구·알림은 분리된 레이어이고 문구·수치·게이지 채움·알림 !·NEW는 이미지에 절대 굽지 않는다. 그림 부족 시 필요한 만큼 시트를 추가한다.
- 원화는 각각 독립 크롭 가능한 **투명 PNG RGBA**, 정확한 R×C 크기, 셀 외곽 2px alpha=0, 그림자까지 침범·겹침 0으로 실제 픽셀 검사한다. 눌림 원화의 외곽 크기·앵커는 기본과 같고 시각적으로 눌리는 차이가 명확해야 한다.
- 아직 승인되지 않은 게임 버튼을 상상해 그리지 않고, 승인된 기존 UI는 무단 변경하지 않는다. **UI 문서/에셋 작업만 했다면 게임 소스·테스트 웹 반영 완료로 보고하지 않는다.**


- **UI 이미지를 새로 만들거나 수정·적용할 때는 이 폴더의 [UI.md](UI.md)를 반드시 읽고 따른다.**
- 기본 이미지에는 가변 숫자·문구·게이지 채움·편지 느낌표(!)/NEW/빨간 점을 그리지 않는다. 상태 정보는 프로그램에서 별도 표시한다.
- 스프라이트 시트는 완전 투명 PNG RGBA, 각 셀 바깥 2px alpha=0, 셀 간 침범/겹침 금지. 실제 픽셀을 검증한다.
- 기존 정상 게임/에셋/버튼/저장 기능을 요청 없이 변경하지 않는다.
- 추가로 상위 저장소의 [공통 AGENTS.md](../AGENTS.md)를 따른다.
