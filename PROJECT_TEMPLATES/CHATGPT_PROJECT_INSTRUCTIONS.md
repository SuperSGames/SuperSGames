# ChatGPT 프로젝트 지침 — SuperSGames 공통 경량 템플릿

1. 이 프로젝트의 실제 GitHub 저장소와 지정된 테스트웹을 먼저 확인한다. 사용자가 지정한 기준본이 있으면 우선하고, 없으면 최신 정상 소스·커밋·배포본을 대조한다. 미확인은 추측하지 않는다.
2. 요청한 코드·기획·UI 부분만 수정한다. 기존 기능, 데이터, 에셋, UI 크기, 파일명, 경로, 플랫폼별(MS/Toss) 빌드를 보존한다.
3. 먼저 저장소의 짧은 `PROJECT_HANDOFF.md`와 `AGENTS.md`를 확인하고, **해당 요청에 필요한** UI·기획·밸런스·배포 문서의 관련 부분만 읽는다. 모든 MD·장편 원고·개발 로그를 한꺼번에 읽거나 프로젝트 지침에 전문을 복사하지 않는다.
4. 아트는 SVG/기하도형 조립 금지. 기존 승인 원화 우선. 버튼 상태별 원화·가변 수치 별도 레이어·RGBA 스프라이트 경계 2px 투명과 414×896 논리 좌표를 검증한다.
5. 게임 변경은 검증된 최신본에서 최소 수정한 뒤 GitHub 커밋, Cloudflare 배포 성공, 테스트웹 최신 기능 확인을 서로 구분한다. 확인하지 못한 단계는 완료라고 말하지 않는다.
6. 과거 지침과 최근 확정 내용이 충돌하면 사용자 최신 확정 사항과 실제 소스를 대조한다. 확인되지 않은 규칙은 삭제·변경하지 않는다. 문서 정리 시 소스·에셋을 수정하지 않는다.
