## 최우선 절대 규칙 — SVG 그림 제작 전면 금지 (예외 없음)

## [최우선] 최신 버전 원본 고정 규칙

- 사용자가 **명시적으로 이전 버전 복원 또는 특정 과거 버전을 기준으로 하라고 요청하지 않는 한**, 모든 제작·수정·병합·복구·HTML/AIT 변환·패키징·테스트·배포는 **실제로 검증한 최신 버전**에서만 시작한다. 이전 버전으로 임의 회귀하거나 새로 재구성한 과거 HTML을 최신이라고 속이지 않는다.
- 작업 직전 GitHub 해당 저장소의 기본 브랜치 최신 커밋·최근 작업 내용·실제 사용 중인 테스트/배포 웹 버전을 확인하여 어느 것이 **요청 대상의 최신 완성본**인지 대조한다. 날짜·파일명·예전 첨부파일만으로 추측하지 않는다.
- 사용자가 특정 웹 주소·경로·빌드(예: `/toss`, Microsoft 심사용)를 지정하면 **그 경로에서 실제 서비스 중인 최신 버전**을 기준으로 한다. 기본 주소, 다른 빌드, 다른 브랜치로 바꿔치기하지 않는다.
- GitHub 최신 파일과 배포된 웹이 다르면 차이를 먼저 확인한다. 배포 원본을 확인하지 못하면 **최신판 확인 불가**라고 보고하고, 오래된 파일을 사용해 무단으로 수정·빌드·덮어쓰기하지 않는다.
- 검증한 최신 원본에 요청 내용만 최소 수정하며 기존 UI·에셋·버튼·게임 기능·광고·결제·진동·설정 등 **지금까지 누적된 수정사항을 전부 유지**한다. 이전 버전 코드로 최신 기능이 사라지지 않도록 한다.
- 완료 시 기준이 된 저장소/브랜치/커밋 또는 테스트 웹 경로, 변경 내용, 실제 검증 범위를 구분해 알린다. AIT 변환본도 기준 최신 HTML과 일치하는지 점검한다.
- 다른 과거 기획·작업일지·지시와 충돌하면 이 원칙을 우선한다. **명시적인 사용자 요청으로 이전 버전을 선택한 경우만 예외**다.


- **절대 금지: SVG로 그리지 않는다.** SVG 파일(.svg), HTML 인라인 `<svg>`, SVG `path`·`rect`·`circle`·`line`·`polygon` 등 어떤 SVG 표현도 캐릭터·아이콘·메달·버튼 그림·장식·배경·삽화·게임판 시각 요소 제작에 사용하지 않는다. **간단한 그림, 임시 리소스, 기능용 선이나 효과라는 이유로도 SVG 제작 예외를 두지 않는다.**
- **SVG 우회 금지:** SVG로 만든 뒤 PNG/WebP로 변환하기, SVG에 이미지를 삽입해 우회하기, 라이브러리·아이콘 패키지가 SVG를 내부 생성하도록 하기, 기존 SVG 에셋을 새 디자인에 재활용하기도 금지한다.
- **그림을 도형으로 짜맞추지 않는다.** CSS 사각형·원·그라디언트·가상요소·box-shadow·clip-path, Canvas 기하 도형·경로, 텍스트 기호·이모지를 조합해 일러스트·아이콘·버튼 그림처럼 만드는 행위도 금지한다.
- **실제 그려진 이미지 사용:** 실제로 제작된 PNG/WebP 등 래스터 이미지 에셋을 우선 재사용하고, 없으면 직접 새 이미지로 그려서 저장한다. 조금 투박해도 도형 조립보다 실제 그림을 사용한다.
- **게임에 연결:** 사용자가 게임 수정·적용을 요청하면 실제 이미지 파일을 올바른 리소스 경로에 배치하고 게임에서 참조·표시하도록 연결한다. 크기·비율·투명도·상태·터치 판정을 검증한다. 보기만 위한 그림 시안이나 가짜 UI로 완료 처리하지 않는다.
- **HTML/CSS/Canvas는 기능 구현 용도만:** 레이아웃, 글자, 입력·터치 판정, 기존 게임 실행에는 사용할 수 있지만 **SVG를 그리거나 CSS/Canvas 도형으로 그림을 대체해서는 안 된다.** 기존 SVG가 기능에 사용 중이면 신규 SVG를 추가하지 않고, 실제 이미지 기반 대안으로 교체할 때 원래 기능이 깨지지 않도록 검증한다.
- **우선순위:** 이 지침이 해당 저장소의 과거 SVG 버튼·아이콘·선·배경 사용 지침과 충돌하면 **무조건 이 절대 금지 지침을 따른다.** 과거 문서에 적힌 SVG 사용 사례는 기록일 뿐 신규 제작 지시가 아니다. 이 지침을 위해 기존 정상 게임 코드를 별도 요청 없이 무리하게 삭제하거나 고치지는 않는다.



## [필수] 공통 UI 원화 강제 규칙

- 새 프로젝트 루트에 중앙 `PROJECT_TEMPLATES/UI.md` 파일을 `UI.md`로 복사한 뒤, UI 아트 생성·수정·게임 적용 전에 반드시 읽고 따른다.
- 기본 UI 이미지에는 가변 숫자·가격·레벨·HP 충전량·버튼 문구·느낌표(!)·NEW·빨간 알림 점·체크를 **절대 미리 그리지 않는다**. 모두 게임 코드의 별도 레이어로 렌더링한다.
- 모든 UI 시트는 **완전 투명 PNG RGBA**, 지정 격자(기본 셀 256×256px), **모든 셀 바깥 2px alpha=0**, 셀 침범·겹침·격자선 금지. 실제 픽셀 검증을 통과한 파일만 사용한다.
- `UI.md`가 없으면 신규 게임 초기화를 완료했다고 보지 않는다.
