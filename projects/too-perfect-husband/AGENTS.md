# 너무 완벽한 내 남편 — 프로젝트 작업 규칙

- 현재 프로젝트 폴더 외 파일과 다른 게임 저장소는 요청 없이 수정하지 않습니다.
- 메인 제목과 부제는 사용자 변경 요청 전까지 유지합니다.
- 텍스트·UI 중심, 장 수 제한 없는 연속극을 유지합니다.
- 삼성 갤럭시 메시지와 안드로이드 카카오톡의 시각 언어 및 목록/채팅방/입력창을 구별합니다.
- 실제 타인 연락처·채팅 데이터를 읽거나 저장하지 않고 가상 데이터를 사용합니다.
- 414×896 고정 논리 화면. `#gameViewport`가 전체 화면, `#game`만 고정 좌표로 스케일합니다.
- `sx = Math.min(1, vw / 414)`, `sy = Math.min(sx, vh / 896)`. 내부 UI 반응형 재배치 금지.
- 전체 게임 프레임은 가로 중앙, 상하 공간 고려한 중앙 정렬. 회전해 가로모드면 플레이 불가 안내.
- `fitGame`은 DOM 준비, rAF 두 번, load/pageshow/resize/orientationchange/visualViewport resize에서 중복 없이 수행하고 0/80/250/700/1500ms 재시도합니다.
- 로딩/새로고침 후 검은 화면을 방지하도록 초기 visibility·opacity·display와 유효한 뷰포트를 검사합니다.
- 미니게임은 장면의 맥락에 맞을 때만 등장하며 스토리 필수 단서를 무작위 확률로 차단하지 않습니다.
- 기존 파일은 최소 변경하며, 정상 동작 확인 없이 배포 성공을 주장하지 않습니다.
- 공개 저장소에 미공개 대본·결말·정체 반전·기밀 정보를 저장하지 않습니다.
- 토스용과 Microsoft Store용 출시는 별도 패키지/정책으로 준비하고, 공용 템플릿 `PROJECT_TEMPLATES/MS_STORE_SUBMISSION.md`를 참조합니다.
