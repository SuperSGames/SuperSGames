# 게임 핵심 기획

**제목:** 너무 완벽한 내 남편  
**부제:** 당신은 누구와 살고 있나요?  
**장르:** 장편 텍스트 막장드라마 + 미스터리 + 상황형 미니게임

## 플레이 감각
- 글과 대사가 서사를 이끕니다. 목표는 **읽고 싶어서 다음 행동을 하게 만드는 것**입니다.
- 조작은 장면의 결과를 바꾸거나 내용을 확인하는 역할입니다. 단순 플레이 시간 늘리기용 퍼즐을 넣지 않습니다.
- 긴장, 코미디, 감동, 오해, 분노, 슬픔, 놀라움이 번갈아 나타납니다.
- 조사 결과는 항상 부정적이거나 동일한 유형의 사건이어서는 안 됩니다.
- 이야기 진행에 필요한 핵심 단서는 운에 맡기지 않습니다. 확률형 요소는 추가 발견/보너스 연출에 한정합니다.
- 감정적으로 중요한 대사 도중에는 조작을 강요하지 않습니다.

## 진행 구조
`소설형 장면 → 이야기상 자연스러운 행동 → 짧은 인터랙션(필요 시) → 단서/감정/관계 변화 → 후속 장면`

## 가족 관계
- 남편은 아내에게 다정한 일상이 있고, 딸에게 실제로 헌신합니다.
- 아내가 가족을 유지하려는 선택에는 관계, 돌봄, 생활, 경제, 기억과 희망이 복합적으로 작용합니다.
- 긍정적인 행동이 다른 잘못을 면책하는 설정은 아닙니다. 관계의 복잡한 감정을 정교하게 묘사합니다.

## 시각 구성
- 화면은 414×896 논리 좌표로 고정, 전체 프레임만 화면에 맞게 축소합니다.
- 대사/서술, 갤럭시 메시지, 안드로이드 카카오톡, 문서, 증거 보관함, 간단한 미니게임은 각각 어울리는 UI를 사용합니다.
- 카카오톡과 SMS를 같은 말풍선 위에 색만 바꾸어 표현하지 않습니다.

## 개발 단계
1. 장편 도입부에 핵심 게임 4~8종을 자연스럽게 연결
2. 자막·대사·메시지·선택·저장 구현
3. 반복 가능한 미니게임 엔진 확장
4. 주요 복선·분기 정합성 검증
5. 실제 모바일 기종별 조작 검증

**주의:** 미공개 스토리의 구체적 반전은 비공개 자료에서 관리합니다.
