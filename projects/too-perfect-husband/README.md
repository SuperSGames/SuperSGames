# 너무 완벽한 내 남편
> 당신은 누구와 살고 있나요?

장편 텍스트 기반 막장드라마·미스터리 모바일 게임의 프로젝트 폴더입니다.

## 게임 개요
- 같은 가족을 중심으로 긴 이야기가 이어지며, 장·화 수를 사전에 제한하지 않습니다.
- 이야기는 대부분 서술, 대사, 문자, 카카오톡 등 **텍스트**로 진행합니다.
- 복잡한 배경 원화 대신 문서·알림·카드·채팅·자물쇠 등 **UI 연출**로 몰입을 만듭니다.
- 조사, 간단한 미니게임, 선택, 증거 연결은 **이야기 속에서 자연스럽게 필요한 순간**에만 등장합니다.
- 단서를 발견하면 의심했던 것과 다른 사정, 오해, 가족애, 슬픔, 예상 못 한 비밀 등이 나올 수 있습니다.
- 플레이 중 선택과 수집한 증거는 일관된 상태로 기록하고, 과거 단서를 다시 활용할 수 있어야 합니다.

## 파일 구조
- `GAME_DESIGN.md`: 핵심 게임 방향 및 전개 규칙
- `MINIGAME_SYSTEM.md`: 재사용형 간단한 게임 조작 시스템
- `STORY_SYSTEM.md`: 드라마/복선/증거 시스템
- `UI_RULES.md`: 삼성 갤럭시 메시지·카카오톡 UI 규칙
- `AGENTS.md`: 개발 시 변경 금지 규칙과 화면 기준
- `prototype/galaxy-messaging-v0.1.html`: 별도 동작하는 메시지/카톡 UI 시안

## 상태
현재 **기획 및 UI 프로토타입 단계**입니다. 본편 게임을 구현하거나 배포한 상태가 아닙니다.

## 비공개 상세 자료
이 폴더가 포함된 `SuperSGames/SuperSGames` 저장소는 **공개(Public)** 상태입니다. 미공개 시나리오의 핵심 반전, 상세 대본, 사건 200개 원본 및 전체 미니게임 목록은 이 공개 폴더에 올리지 않고 별도 비공개 보관 대상으로 둡니다.

다른 게임 저장소(`sword`, `bubble`, `dig`, `defense`, `sokoban`)는 이 프로젝트 작업에서 수정하지 않습니다.
