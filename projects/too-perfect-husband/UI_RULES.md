# 《너무 완벽한 내 남편》 — 삼성 갤럭시 문자·카카오톡 UI 디자인 규칙 v0.1

공식 제목: **너무 완벽한 내 남편**
부제: **당신은 누구와 살고 있나요?**

## 1. 절대 원칙
- 스토리 85~90%를 서술·대사·문자·카카오톡 같은 텍스트 UI로 진행한다. 그래픽 장면을 억지로 만들지 않는다.
- **문자와 카톡은 같은 말풍선 스킨을 공유하지 않는다.** 각 앱의 목록→채팅방→알림→입력창이 모두 다른 구조와 색으로 보여야 한다.
- 갤럭시 안드로이드의 상단 상태 표시줄, 하단 시스템 내비게이션, 앱 열림/뒤로가기 동작을 한 기기처럼 일관되게 적용한다.
- 인물의 채팅방 이름, 프로필, 최근 메시지, 시간, 읽음 상태, 알림 수는 화면 간 연결되어야 한다. 연출적 조작은 신빙성을 해치지 않게 사건의 일부로만 사용한다.
- 게임용 튀는 테두리와 보상 메시지를 대화방 위에 항상 띄우지 않는다. 문자를 읽는 동안에는 **실제 메신저를 보고 있다고 느끼게** 한다.
- 원본 개인정보나 실제 타인의 문자 및 카카오톡 데이터는 불러오지 않는다. 모든 대화/연락처/화면은 게임 내 가상의 시뮬레이션이다.

## 2. 삼성 갤럭시 문자 메시지 (SMS/RCS 연출)
- 밝은 흰색/매우 옅은 회색 배경, 현대적인 One UI 계열 상단 바.
- 기본 대화 목록: 상대 이름/전화번호, 최근 문장, 시간, 읽지 않은 메시지 표식.
- 대화방: 오른쪽 파란 발신 말풍선, 왼쪽 연한 회색 수신 말풍선, 대화 날짜/시각.
- 상단 뒤로가기, 연락처명, 검색, 옵션. 하단 첨부·문자 입력·전송 버튼.
- 예약 문자와 번호 불명 문자, 병원·택배·은행 SMS 등은 현실적인 발신자 표기로 구분.
- SMS와 RCS 기능을 한 번에 가짜로 섞지 않는다. 읽음 상태/리액션 같은 기능은 해당 대화가 RCS로 설정된 경우에만 상황에 맞춰 사용.
- 문자 앱은 기종·국가·시스템에 따라 실제 외형이 달라질 수 있음. **이번 시안은 삼성 메시지 계열의 익숙한 흰/파란 대화 화면을 참조**하며 한 모델의 픽셀 단위 복제라고 주장하지 않는다.

## 3. 카카오톡 (갤럭시 Android 앱)
- 일반 대화방의 회청색 배경, 내가 보낸 노란 말풍선, 받은 하얀 말풍선을 사용.
- 상대 프로필 아바타와 상대 이름은 수신 메시지 쪽에 표시. 시각, 읽지 않은 수(필요한 경우)를 말풍선 옆에 배치.
- 상단 뒤로가기/채팅방 이름/검색/메뉴, 하단 +·입력 필드·전송 버튼. 별도의 채팅 목록 및 하단 탭.
- 카톡 내용에만 필요한 알림, 긴 메시지, 사진/선물/단체방/삭제 메시지 등은 **실제 사건에서 등장한 기능만** 활성화.
- 게임 원본 화면에서는 카톡 스타일을 흉내 낸 가짜 문자 UI가 나오지 않게 한다.
- 카카오톡은 서비스 업데이트에 따라 UI가 달라질 수 있으므로 게임에서 사용하는 앱 버전의 화면을 기준 이미지로 고정하고 전체 스토리를 통일한다.

## 4. 진행 흐름
1. 소설형 스토리에서 삼성 갤럭시 알림이 온다.
2. 플레이어가 **문자**를 누르면 메시지 앱 목록/대화방을 연다.
3. **카카오톡**을 누르면 카톡 채팅 목록/채팅방을 연다.
4. 읽는 행동은 일반 메신저처럼. 조사할 만한 메시지를 길게 누르거나 선택할 때만 증거 기록 또는 정보 확인.
5. 뒤로가기로 채팅 목록으로 돌아가고, 다시 뒤로가면 스토리 화면으로 돌아간다.
6. 중요한 반전은 UI를 방해하는 팝업보다 새로운 메시지, 발신자, 타이밍, 옛 대화 재확인으로 전달.

## 5. 화면 좌표 절대 기준
- #gameViewport(전체 화면) → #game(414×896 논리 px 고정) 구조.
- sx=Math.min(1, viewportWidth/414), sy=Math.min(sx,viewportHeight/896).
- 오직 #game에 전체 변환 적용; 내부 말풍선/글씨/키보드에 개별 화면 맞춤 확대 금지.
- 계산된 렌더 크기를 기준으로 화면 중앙에 배치하며 가로 모드에서는 게임 플레이를 막고 세로 회전 안내.
- 창, 폴더블, 브라우저 화면 크기 변화 시 전체 비율이 안정적으로 유지되도록 fitGame idempotent 처리.
- 실폰 삼성 Galaxy의 폰트/키보드/상태 표시줄은 브라우저 안에서 100% 재현할 수 없으므로 **실행 가능한 HTML 시안과 실제 폰 화면을 구분**한다.

## 6. 구현 상태
- `너무완벽한내남편_갤럭시_문자카톡_UI시안_v0.1.html`: 별도로 실행 가능한 **UI 프로토타입**. 소설→문자 앱→카카오톡 앱, 채팅방 선택, 대사 보기, 단서 저장 시연.
- **아직 본편 스토리/저장 시스템/실제 메시지 앱과 통신하는 코드가 아니다.**
